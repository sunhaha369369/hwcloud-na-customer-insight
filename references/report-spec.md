# 报告结构与写作规范

报告不是「数据展示」，是「决策材料」。整份报告按 **判断 → 决定 → 证据 → 明细** 的顺序组织：
读者看完第一屏就该知道自己要做什么，而不是先看十二张图。

## 1. 章节骨架（report.html 已实现）

| 节 | 标题 | 必须回答的问题 | 给谁看 |
|---|---|---|---|
| 首屏 | 本期结论 | 一句话：盘子多大、钱在哪、最该担心什么 | 主管 |
| — | KPI 带（8 个） | 与上期比，哪些指标动了 | 主管 |
| 00 | 决策摘要 | 要拍板哪几件事、谁拍、不拍会损失什么 | 主管/经营会 |
| 01 | 数据与口径 | 数据从哪来、哪里不完整、结论有多可信 | 数据方 |
| 02 | 客户分层与画像 | 钱集中在谁身上、哪块收入在裸奔、每类客户怎么打 | 主管/客户经理 |
| 03 | 需求与痛点 | 客户在抱怨什么、哪些是共性、先解决哪个 | 产品/服务 |
| 04 | 机会点与优先级 | 钱在哪里、凭什么说是机会、下一步做什么 | 销售 |
| 05 | 趋势预警 | 谁在恶化、谁在爆发、多急 | 客户经理 |
| 06 | 30/60/90 天路线 | 谁在什么时候做什么 | 全体 |
| 07 | 上期动作闭环 | 上期标红的客户这期好没好、说好的动作有没有用 | 经营会 |
| 08 | 方法与口径 | 公式、证据分级、边界、免责 | 复核 |

## 2. 首屏结论（verdict）

一段话，三层信息：

1. **盘子**：客户数 + 窗口消费 + 同比 + 集中度；
2. **最刺眼的矛盾**：流失预警客户点名 + 年化金额 + 风险敞口，与增长机会金额对比；
3. **排序建议**：先防御还是先扩张，用一句话给结论（绿色/红色高亮关键词）。

反例（不要这样写）：
> 本期客户整体表现良好，部分客户存在流失风险，建议加强客户经营。

正例：
> 12 家客户窗口消费 3.09 亿，同比 8.4%；S/A 两层贡献 74.3% 收入。但 2 家客户已进入流失预警
> （天穹能源、智学教育集团），对应年化 2,027 万、风险敞口 5,774 万，与同期 4,784 万的增长机会相比，
> **保盘子的优先级高于谈增量**。

## 3. 决策摘要（00 节）——本报告的核心差异

每条决策必须四要素齐全，缺一不可：

| 要素 | 写法 | 反例 |
|---|---|---|
| 问题 | 一个可以用「是/否」回答的问句 | 「需要关注续约风险」 |
| 依据 | 支撑判断的数字，2 句以内 | 「客户情况不太好」 |
| 决策人 | 具体角色（客户成功/产品/销售主管），不是「相关部门」 | 「领导」 |
| 代价 | 不决定的量化损失 | 「可能影响业绩」 |

「不决定的代价」这一栏是整份报告最容易被跳过、又最能推动会议产出的一栏。
算不出精确值时给区间并标注假设（如「按 50% 流失概率计」）。

## 4. 图表选型

| 图表 | 用途 | 实现 |
|---|---|---|
| 横向条形 | 分类对比（分层收入、生命周期、机会类型、证据构成） | `svgchart.hbar` |
| 气泡矩阵 | **价值 × 风险**四象限，气泡=机会金额 | `svgchart.scatter`（传 `split_x/split_y`） |
| 排名斜率 | **声量排名 vs 影响排名**，找「不吵但贵」的问题 | `svgchart.rank_slope` |
| 折线/面积 | 月度走势 | `svgchart.line` |
| 迷你条 | 表格内数值横向对比 | `svgchart.mini_bar` |

全部是**内联 SVG**：不依赖 CDN、断网可看、可直接打印成 PDF、可整段贴进汇报材料。

### 两条图表纪律

1. **标题写结论，不写名词**。「各层级收入贡献」→「S+A 两层 4 家客户贡献 74% 收入」。
   读者只看标题就该知道结论，图只是证据。
2. **象限文字不进图**。气泡会和角落标签打架，把四个象限的解释放到图下方的四格条里，
   同时给每个象限的客户数——这样既好看又多了信息。

## 5. 证据分级（贯穿全文）

每一条判断都标注它有多硬：

| 等级 | 含义 | 销售该怎么用 |
|---|---|---|
| 事实 | 直接来自合同、交易、流失记录 | 可直接进 CRM 跟进 |
| 推断 | 事实基础上的合理外推（使用率→扩容需求） | 先确认再投入 |
| 假设 | 行业规律推导的可能性（交叉销售意愿） | 必须先验证场景再申请预算 |

报告 01 节与 08 节各列一次构成比例。**假设占比高不是缺陷，藏起来才是。**

## 6. 版式约束

- 浅色主题，主色 `#1f4e79`，风险 `#b3261e`，正向 `#2f7d32`；涨用红、跌用绿（国内习惯）；
- 表格字号 12.2px，正文 14px，KPI 数字 21px；
- 打印 A4：`@page{size:A4;margin:13mm}`，卡片与表格 `page-break-inside:avoid`；
- 半宽卡片里的图表按实际像素宽度绘制（`width=470`），否则 SVG 等比缩小会让字号不可读；
- 表格数字列右对齐并开 `tabular-nums`，方便竖着比大小。

## 7. 措辞红线

| 不要写 | 改成 |
|---|---|
| 客户满意度很差 | 近 3 月工单反馈中负面占比 X%（n=Y） |
| 客户普遍反映 | N 家客户提及（占 X%）——**≤1 家不许说「普遍」** |
| 预计可带来 X 万收入 | 预估年化增量 X 万（口径：同业中位 × 赢率 30%），排序用 |
| 客户将要流失 | 流失风险 88 分（合同 29 天到期 + 竞品信号 90% + 用量连续 3 月下滑） |
| 建议加强沟通 | 48 小时内完成用量诊断，出具竞品对比与续约商务方案 |
| 该客户有需求 | 同业 67% 已采购数据库，该客户未覆盖（覆盖 5/12 品类） |
| 本月情况整体向好 | 删掉。没有对比对象的形容词一律不进报告 |
